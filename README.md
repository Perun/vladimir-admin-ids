# Vladimir Admin IDs

Ein kleines WordPress-Plugin von Vladimir Simović. Es zeigt die IDs von Beiträgen, Seiten, Medien, Kommentaren, Kategorien, Schlagwörtern und Benutzern direkt in den Verwaltungslisten an. Auch eigene Beitragstypen und Taxonomien mit WordPress-Listenansicht werden unterstützt.

Bei Beiträgen und Seiten kommt eine Spalte **ID-Link** hinzu. Mit **Kopieren** übernimmst du eine Adresse wie `/?p=123` oder `/?page_id=456`. Wenn der Browser die Zwischenablage sperrt, kannst du die Adresse im Feld markieren und manuell kopieren. Ein ID-Link gewährt keine zusätzlichen Leserechte. Für Entwürfe steht dir die WordPress-Vorschau zur Verfügung.

## Installation

1. Lade unter [Releases](../../releases) das Plugin-Paket `vladimir-admin-ids-0.1.3.zip` herunter.
2. Öffne in WordPress **Plugins → Plugin hinzufügen → Plugin hochladen**, wähle das ZIP und aktiviere das Plugin.
3. Unter **Ansicht anpassen** kannst du die Spalten pro Liste ein- und ausblenden.

**Voraussetzungen:** WordPress ab 6.8 und PHP ab 8.1.

**Wechsel von 0.1.2 oder älter:** Deaktiviere zuerst die bisherige Version. Mit Version 0.1.3 erhielt das Plugin ein neues Verzeichnis. WordPress führt beide Fassungen daher als separate Plugins.
